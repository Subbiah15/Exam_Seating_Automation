Authentication Flow

  1. Signup: Users create account with appropriate role (admin/teacher or student)
  2. For Admin/Teacher: Enter name, username, email, password
  3. For Student: Enter name, username, email, password, and Student ID
  4. Login: After signup, login with credentials on the login page
  5. Redirection:
    • Admin/Teacher → Dashboard (index.html)
    • Student → Student Dashboard (student-dashboard.html)

System Architecture

  • Backend: FastAPI with JWT authentication
  • Frontend: HTML5 with vanilla JavaScript
  • Password Security: bcrypt hashing
  • Token: JWT-based with 24-hour expiration
  • User Storage: JSON-based (can be upgraded to database)
  • CORS: Enabled for frontend-backend communication

Key Features

  • Separate registration forms for each role

API Endpoints

POST   /api/auth/signup     - Register new user (admin/teacher/student)
POST   /api/auth/login      - Login and get JWT token
GET    /api/auth/me         - Get current user info (requires auth)
